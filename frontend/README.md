# BBL Bookmark Manager — Frontend

React + Vite + TypeScript. See the repo root `CLAUDE.md`, `API_DESIGN.md`,
and `DECISIONS.md` for the frontend rules and decisions this app follows
(routing, auth flow, token storage).

## Scripts

- `npm run dev` — start the Vite dev server (port 3000)
- `npm run build` — type-check and build for production
- `npm run format` — format `src/` with Prettier
- `npm run lint` — lint with Oxlint
